# Hayyik-Platform

# About the project
"Hayyik" is an interactive web application specialized in exploring residential neighborhoods. It aims to empower users to understand the geographical and service-oriented nature of residential areas through an advanced digital interface that blends technical precision with ease of use.

# Technologies Used
-HTML5
-CSS3
-JavaScript
-Google Maps API

# Target Audience
-Home Seekers
-Residents
-Real Estate Investors
